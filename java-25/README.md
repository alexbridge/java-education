# Java 25 – Version Differences

## Goal
Practice key language and runtime changes from Java 11 to 25 with focused examples.

## Features to Train
1. [final] **Switch Expressions** (Java 14) — `->`, multi-value labels, `yield`
2. [final] **Text Blocks** (Java 15) — `"""`, auto-stripped indent
3. [final] **Records** (Java 16) — immutable carriers, auto accessors/constructors
4. [final] **Pattern Matching for `instanceof`** (Java 16) — type check + bind without cast
5. [final] **Sealed Classes & Interfaces** (Java 17) — `sealed`, `permits`, exhaustive checks
6. [final] **Virtual Threads** (Java 21) — Project Loom, `Thread.ofVirtual()`
7. [final] **Pattern Matching for `switch` & Record Patterns** (Java 21) — `when`, record deconstruction
8. [final] **Sequenced Collections** (Java 21) — `getFirst()`, `getLast()`, `reversed()`
9. [final] **Unnamed Variables & Patterns** (Java 22) — `_` discard
10. [final] **Stream Gatherers & Enhancements** (Java 24) — `Stream.gather()`, `Stream.toList()`
